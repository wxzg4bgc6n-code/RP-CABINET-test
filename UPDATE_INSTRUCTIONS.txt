RP CABINET — ОБНОВЛЕНИЕ ДО TEST v96

Этот архив предназначен для загрузки поверх уже опубликованной v95.

1. Не удаляй содержимое репозитория перед обновлением.
2. Загрузи все папки и файлы из архива в корень репозитория с заменой совпадающих файлов.
3. Файла js/config/google-drive.js в архиве обновления специально нет.
4. Твоя настроенная API key Google Drive поэтому останется без изменений.
5. После публикации один раз обнови панель через Ctrl + F5.

Проверка после публикации:

- в панели указан TEST v96;
- нижней кнопки «Найти в материалах» нет;
- при наведении на аватар на ПК появляется карандаш;
- на телефоне карандаш на аватаре виден постоянно;
- после выбора фотографии открываются кадрирование и ползунок масштаба;
- сохранённая фотография заменяет Google-аватар и не перезагружается при каждом обновлении интерфейса;
- загруженный скриншот появляется без долгой повторной загрузки;
- нажатие на скриншот открывает его на весь экран внутри панели;
- публичная ссылка показывает облегчённые миниатюры быстрее;
- в публичной ссылке отображается аватар владельца отчёта;
- при удалении скриншота он исчезает из панели и с Google Диска сразу.
