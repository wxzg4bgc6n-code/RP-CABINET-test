RP CABINET — ОБНОВЛЕНИЕ ДО TEST v104

Причина ошибки 403:
полные архивы v98–v103 содержали старый Firebase API key в js/config/google-drive.js и могли перезаписать ключ RP CABINET Drive Browser, который был вставлен вручную. Загрузка скриншотов продолжала работать по OAuth, но публичный report.html получал 403.

Как обновить:

1. Загрузи всё содержимое папки RP_CABINET_v104_PUBLIC_REPORT_KEY в корень репозитория.
2. Сохрани структуру assets, css, data, documentation, js и _tools.
3. Не возвращай proof-service и node_modules.
4. После публикации нажми Ctrl + F5.
5. Удали старую нерабочую ссылку отчёта и нажми «Сформировать отчёт» заново.
6. Панель один раз попросит ключ RP CABINET Drive Browser. Вставь тот ключ, который ты ранее копировал из Google Cloud.
7. Сначала панель проверит публичное открытие отчёта и только затем скопирует ссылку.

Важно:
- ключ больше не нужно вставлять в js/config/google-drive.js;
- он сохраняется в localStorage браузера;
- новая ссылка содержит параметр pk и продолжит работать после следующих обновлений;
- на другом устройстве ключ потребуется ввести один раз при первом формировании отчёта;
- старую сохранённую ссылку можно обновить повторным копированием из панели; если отчёт уже удалён, сформируй его заново.

Проверка:
- видимый бейдж TEST v104 · Public report key;
- новая ссылка содержит id= и pk=;
- ссылка открывается в режиме инкогнито сразу после формирования;
- аватар и скриншоты отображаются;
- повторное формирование в том же браузере больше не просит ключ;
- README содержит только v104, v103 и v102.
