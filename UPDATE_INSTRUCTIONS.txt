RP CABINET — ОБНОВЛЕНИЕ ДО TEST v98

Этот архив предназначен для загрузки поверх уже опубликованной v96.

1. Не удаляй содержимое репозитория перед обновлением.
2. Загрузи все папки и файлы из архива в корень репозитория с заменой совпадающих файлов.
3. Файла js/config/google-drive.js в архиве обновления специально нет.
4. Твоя настроенная API key Google Drive поэтому останется без изменений.
5. После публикации один раз обнови панель через Ctrl + F5.

Проверка после публикации:

- в панели указан TEST v98;
- в USAF → Тесты открывается «Экзамен по УАК и ПК» из 20 вопросов;
- при задаче повышения по УАК/ПК в профиле появляются памятка и экзамен;
- крестик виден у каждого скриншота, даже если сформирован отчёт;
- крестик удаляет файл с Google Диска и из панели;
- если файл уже удалён с Диска, его зависшая запись всё равно удаляется из панели;
- кнопка «Удалить все скриншоты» очищает весь список текущего контекста;
- при активном отчёте удаление скриншота также отключает публичную ссылку;
- если Google не подтвердил удаление, панель предлагает отдельно убрать только зависшие записи;
- повторный запрос Google возможен после истечения временного токена или новой сессии, но не после каждого отчёта.
