RP CABINET — ОБНОВЛЕНИЕ ДО TEST v104

Этот архив предназначен для полной замены файлов опубликованной панели.

1. Загрузи всё содержимое папки RP_CABINET_v104_RP_HELPER_LATEST в корень репозитория.
2. Сохрани структуру папок assets, css, data, documentation, js и _tools.
3. Не загружай node_modules, .env, OAuth client secret, access token или refresh token.
4. Не возвращай удалённую папку proof-service.
5. Проверь, что твой настроенный js/config/google-drive.js не был заменён старой копией.
6. После публикации один раз обнови панель через Ctrl + F5.

Проверка после публикации:

- в панели указан TEST v104;
- вместо серого глобуса во вкладке браузера отображается значок RP;
- значок также отображается у публичного отчёта и в мобильной закладке;
- во второй плашке боковой карусели отображается RP-Helper и его актуальная версия;
- нажатие «Скачать RP-Helper» начинает загрузку RP-Helper.zip из последнего GitHub Release;
- при недоступности GitHub API остаются версия 1.0 и резервная ссылка на последний Release;
- Google Drive, аватар, скриншоты, отчёты и синхронизация продолжают работать как в v101;
- прогресс и профиль после обновления не сбрасываются;
- README содержит только v104, v103 и v102.

Как публиковать следующую версию RP-Helper:

1. Создай новый GitHub Release, не заменяй старый Release.
2. Название Release укажи в формате RP-Helper 1.1.
3. Тег укажи в формате program-v1.1.0.
4. Прикрепи архив с точным именем RP-Helper.zip.
5. Сделай Release последним опубликованным.
6. Панель автоматически обновит видимую версию и ссылку максимум через 5 минут.
