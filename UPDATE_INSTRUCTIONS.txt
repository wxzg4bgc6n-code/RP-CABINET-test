RP CABINET — ОБНОВЛЕНИЕ ДО TEST v108

1. Для GitHub используй маленький пакет v108.
2. Загрузи его содержимое поверх текущего репозитория, сохраняя структуру папок.
3. Не удаляй и не заменяй js/config/public-config.js — он остаётся твоим постоянным файлом с браузерным Drive API key.
4. Дождись завершения GitHub Pages и нажми Ctrl+F5.
5. Проверь: Ammunation в тесте USAF, новые значения премий, отчётную неделю воскресенье–суббота.
6. При удалении публичного отчёта ссылка и скриншоты должны исчезать из панели сразу; очистка Google Drive выполняется фоново при активном доступе к Drive.

Полный архив предназначен для резервной копии. В нём public-config.js не поставляется намеренно: лежит только js/config/public-config.example.js, чтобы не затереть настроенный ключ.
