- Старые документы v79/v77/default читаются только для одноразового создания v80.

- Все данные профиля, прогресс по контекстам, закрепления, отчёты и скриншоты.
- Неограниченное количество скриншотов на пункт и лимит 15 МБ на один файл.

# Отчёт о переходе v78 → v79

Дата: 24.07.2026.

## Полностью заменено

- Удалена старая синхронизация, которая сравнивала локальный и облачный профиль и могла отправить устаревший снимок при обновлении страницы.
- Создан новый документ Firebase `default_v79_realtime` с каноническим `state` и последовательным `syncRevision`.
- Локальный кэш больше не участвует в выборе победителя и не отправляется при запуске.
- Каждое действие пользователя хранится отдельной уплотняемой операцией и применяется Firestore-транзакцией поверх последней серверной ревизии.
- `onSnapshot` применяет изменения в реальном времени на всех открытых устройствах и вкладках.
- Закрытое устройство при открытии сначала получает Firebase; старый локальный кэш не может откатить другое устройство.
- Офлайн-операции сохраняются до подтверждения и после восстановления сети накладываются на свежий серверный профиль.

## Миграция

- Старые локальные ключи v77 читаются только при отсутствии кэша v79.
- При отсутствии нового документа v79 профиль один раз переносится из `default_v77`, затем из `default`, и только затем — из локального кэша.
- Старые сборки v77/v78 не имеют доступа к новому пути и не могут перезаписывать v79.

## Сохранено

- Неограниченное количество скриншотов из v78.
- Все задания, тесты, изображения, отчёты и внешний вид.
- Раздельный прогресс по контекстам и плавная анимация кольца.
