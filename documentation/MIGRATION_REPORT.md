# Отчёт о переходе v70 → v71

Дата: 23.07.2026.

## Добавлено

- системы повышения Academy, MA, USAF, MP, DF, SD и ED из обновлённого Discord-файла;
- отсутствовавшие ступени USAF 1→2, 2→3, 8→9 и 9→10;
- отдельная операция синхронизации для снятия галочки;
- локальная резервная копия готового профиля;
- `recoveryState` в Firebase для восстановления после неполного снимка.

## Изменено

- скриншот теперь требуется только для участия в СО/специальной операции и ГМП;
- пункты без изображения остаются в общем отчёте как выполненные;
- загрузка профиля выбирает более полноценную копию между рабочим и резервным состоянием;
- дата регистрации восстанавливается по самой ранней корректной сохранённой дате;
- README и все номера версии обновлены до v71.

## Сохранено без выдумывания

- для RAP и SAS в текущем `ARMY_PANEL_DS_INFO.txt` нет отдельной системы повышения;
- до появления точных условий эти разделы продолжают использовать общий список;
- тексты и визуальное оформление Academy/USAF не изменены.

# История перехода v69 → v70

Дата: 23.07.2026.

## Добавлено

- отдельная очередь подтверждений ниже полного прогресса;
- загрузка нескольких оригинальных скриншотов на один пункт;
- правило «тест/экзамен — выполнено без изображения»;
- одна публичная ссылка на полный отчёт;
- отдельная адаптивная страница `report.html`;
- ручное удаление изображения до формирования отчёта;
- ручное удаление всего отчёта;
- автоматический срок хранения 8 дней;
- Vercel Blob Client для прямой загрузки без ограничения Vercel Function в 4,5 МБ;
- отдельный сервер `proof-service`.

## Исправлено

- пустой запуск телефона больше не записывается поверх готового профиля;
- во время проверки Firebase показывается загрузка, а не первичный выбор;
- дата регистрации не заменяется временем синхронизации;
- при конфликте сохраняется самая ранняя дата создания;
- номер в нижней плашке обновлён до v70.

## Не изменено

- тексты и ответы Academy/USAF;
- существующие изображения;
- постоянные ключи локального профиля;
- текущая схема Firebase-профиля и вход через Google;
- папка v69.

## До публикации

Функция загрузки остаётся заблокированной, пока не развёрнут `proof-service` и его адрес не внесён в `js/config/proof-service.js`. Это сделано специально: панель не должна делать вид, что файл сохранён, если внешнее хранилище ещё не подключено.
