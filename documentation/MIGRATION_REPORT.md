# Переход v104 → v105

## Исправлено

После v104 загрузка скриншота могла завершаться на Google Drive, но запись не появлялась в панели. Причина: `uploadProof()` строил публичный media URL через ключ отчётов, который теперь вводится отдельно.

В v105:

- `uploadProof()` и `uploadAvatar()` сохраняют Drive thumbnail URL, не требующий API key;
- профиль принимает файл с `fileId`, даже если `url` отсутствует;
- публичный ключ нужен только для JSON-отчёта и полного media fallback;
- синхронизация `default_realtime` не изменена.
