# Переход v103 → v104

## Причина

В v103 публичное чтение JSON-отчёта зависело от ключа, записанного прямо в `js/config/google-drive.js`. Полное обновление могло вернуть старый Firebase API key. OAuth-загрузка скриншотов при этом работала, но анонимный запрос `report.html` получал `403`.

## Изменение

- Добавлен `js/config/google-drive-public-key.js`.
- Ключ вводится владельцем при первом формировании отчёта.
- Ключ хранится локально и передаётся в ссылке параметром `pk`.
- Перед копированием ссылка проверяется реальным анонимным запросом.
- Нерабочий manifest удаляется и не сохраняется как готовый отчёт.
- Сохранённые отчёты без `pk` обновляются при повторном копировании ссылки; удалённые отчёты создаются заново.
