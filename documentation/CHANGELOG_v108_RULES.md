## Премии

- Дежурство на КПП: 3 → 1,5 балла за час.
- Патруль штата: 3 → 1,5 балла за час.
- Добавлен Арест (КПЗ/ФТ): 1 балл.
- Дроп: 1 → 2 балла.
- Поставка материалов/аптечек: 1,5 → 2,5 балла.
- Чёрный рынок: 2,5 балла без изменения.
- Шпак: 1,5 → 3 балла.
- Отбитие ФЗ/ФТ: 3 балла без изменения.
- Защита поезда: 4 балла без изменения.
- Рейд/Оцепление: 5 баллов без изменения.
- Проведение лекции: 1 балл; экзамена: 1,5; тренировки: 2,5 — без изменения.
- ВФМП или МФМА: 1,5 → 2 балла.
- ГМП → ГМП / ВЗЧ / ОВЖ: 4 балла.
- Добавлен отчёт в спец. связи: 1 балл, без дубликатов.

Подтверждение спецопераций для премии: только через логи меню фракции. Скрин «рядом с дропом» не засчитывается. Исключения: Отбитие ФЗ/ФТ и Рейд/Оцепление.
