# Архитектура RP Cabinet v109

- Firebase Firestore — основной источник состояния профиля.
- Google Drive — скриншоты, аватар и JSON-манифесты публичных отчётов.
- OAuth `drive.file` — операции владельца с файлами.
- `js/config/public-config.js` — постоянный браузерный API key для анонимного чтения публичного JSON-отчёта.
- `report.html` читает ключ с домена панели; ключ не передаётся в URL.
- `localStorage` не используется для распространения публичного API key.
- `users/{uid}/profiles/default_realtime` остаётся постоянным облачным документом.


## Первый запуск и онбординг

Первое создание профиля управляется отдельным слоем:

- разметка этапов — `index.html`;
- оформление и переходы — `css/features/onboarding.css`;
- состояние этапов — `js/features/onboarding.js`;
- итоговая запись профиля — `js/app.js`.

Последовательность: приветствие → назначение панели → ник → проект/направление → организация. После завершения открывается вкладка «Прогресс», где выбираются раздел и ступень. Онбординг не создаёт отдельное хранилище и не дублирует профиль: итог сохраняется существующей функцией `save()` и синхронизируется через прежний Firebase-документ.


## v109 — структура памятки УАК/ПК USAF

`data/usaf/law-guide.js` организован в два смысловых уровня: сначала практические действия и материалы для бойца USAF, затем общие правила государственных фракций, уголовные дела и допросы. Блок краткой выжимки экзамена и служебные предупреждения удалены. Вопросы для сдачи выводятся открытыми карточками, а последовательность действий бойца оформлена отдельным линейным визуалом. Стили находятся в `css/features/usaf-law.css`.

## v108 — удаление публичных отчётов

При удалении публичного отчёта `reportsByContext` и соответствующий `proofsByContext` очищаются сразу и синхронизируются в `users/{uid}/profiles/default_realtime`. ID отчёта записывается в `reportDeleteTombstones`, а Drive-файлы — в `driveCleanupQueue`. Очередь также хранится в Firebase и повторяется при наличии действующего Google Drive access token. Tombstone фильтрует удалённый report ID при входящих snapshot, поэтому старая вкладка не возвращает ссылку в интерфейс.

## v108 — премии и правила

Прайс премий находится в `index.html`, а нормализация ранее выбранных активностей — в `js/app.js`. Диапазон отчётной недели вычисляется локально как воскресенье–суббота. Актуальные для USAF выдержки из присланных правил находятся в `data/usaf/law-guide.js`; вопрос Ammunation — в `data/usaf/tests.js`.
