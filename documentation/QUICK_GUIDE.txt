RP CABINET v70 — КРАТКАЯ ПАМЯТКА

1. На GitHub загружать всё содержимое папки v70, включая report.html, css, data, js, documentation и proof-service.
2. Не загружать proof-service/node_modules и локальные .env/.env.local.
3. В GitHub Pages остаются index.html и report.html. Папка proof-service разворачивается отдельным проектом Vercel.
4. Рабочий API уже указан в js/config/proof-service.js: https://rp-cabinet-proof-service.vercel.app.
5. Тексты и тесты менять только в data/academy и data/usaf.
6. Ступени менять в data/levels.js, задания — в data/progress/.
7. Нужен ли скриншот, менять только в data/progress/proof-rules.js.
8. Общие стили менять в css/core.css или css/features/.
9. Мобильные размеры и расположение менять только в css/responsive/mobile.css.
10. Не создавать отдельный index для телефона и не дублировать тексты.
11. Не менять постоянные ключи из js/core/storage-config.js.
12. Не сохранять изображения в Firebase/localStorage и не превращать их в Base64.
13. Не обрезать и не сжимать скриншоты: в отчёте используется оригинальный файл.
14. Не разрешать облачную запись до окончания загрузки профиля.
15. Дату регистрации брать только из account.createdAt; не использовать lastSync/updatedAt/дату Google.
16. При новой версии менять номер сразу в js/core/version.js, css/core.css, meta index.html и памятке.
17. После публикации полностью обновить страницу на ПК и телефоне.
18. Перед включением пользователям проверить адрес Vercel без VPN с ПК и телефона.
