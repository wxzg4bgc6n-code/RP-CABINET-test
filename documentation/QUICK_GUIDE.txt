RP CABINET v104 — КРАТКАЯ ПАМЯТКА

1. На GitHub загружать index.html, report.html, assets, css, data, js, documentation, _tools, README.md и build-summary.json.
2. Папки proof-service в v104 нет.
3. Не загружать node_modules, .env, client secret, access token или refresh token.
4. В Google Cloud проекта rp-cabinet включить Google Drive API.
5. В OAuth Data Access добавить https://www.googleapis.com/auth/drive.file.
6. В Web OAuth client и API key разрешить домен GitHub Pages.
7. API key для публичного отчёта находится в js/config/google-drive.js.
8. Сами изображения хранятся на личном Google Диске пользователя.
9. Firebase хранит только метаданные, прогресс и ссылки.
10. Канонический документ синхронизации: users/{uid}/profiles/default_realtime.
11. Обновление страницы выполняет чтение и не пишет локальный кэш в облако.
12. Скриншоты: PNG/JPG/WEBP, до 15 МБ, без лимита количества на пункт.
13. Крестик удаляет один скриншот, а кнопка «Удалить все скриншоты» очищает все файлы текущего контекста; автоматическая очистка оставшихся файлов выполняется через 8 дней.
14. Публичный report.html открывается без Google-входа и не ведёт обратно в панель.
15. Аватар: карандаш, кадрирование, масштаб 1×–3× и один итоговый WebP 512×512.
16. Аватар не удаляется восьмидневной очисткой.
17. README должен содержать только три версии: v104, v102 и v101.
18. В USAF → Тесты экзамен УАК/ПК находится в блоке «Экзамены других отделов» и содержит 17 вопросов; вопрос №7 показывает четыре ситуации обычными вариантами ответа.
19. Памятка и экзамен УАК/ПК автоматически подставляются к соответствующей задаче повышения.
20. При новой версии одновременно менять version.js, CSS-бейдж, meta architecture, cache-busting, README, QUICK_GUIDE и build-summary.
21. Access token Drive временный: до окончания срока он сохраняется между вкладками и перезапусками браузера; после истечения Google требует обновить токен.
22. OAuth Audience в статусе Testing сбрасывает разрешения тестовых пользователей через 7 дней; для постоянного использования нужен статус In production.
23. Плашка RP-Helper скачивает RP-Helper.zip из GitHub Release program-v1.0.0; ссылка находится в js/features/sidebar-promo.js.
24. Иконка вкладки и закладок хранится в favicon.ico и assets/icons; подключение есть в index.html и report.html.
