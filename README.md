# RP Cabinet v68 — мобильная оболочка и безопасная синхронизация

Версия создана копией подтверждённой модульной v67. Папка v67 и контрольный корневой `index.html` v66 не изменены.

## Что открывать и загружать на GitHub

Загружать нужно **всю папку v68 с сохранением структуры**. Главная страница — `index.html`. CSS, JavaScript, данные и изображения подключаются относительными путями, поэтому отдельные файлы из папки удалять нельзя.

## Где теперь что находится

| Что меняется | Файл или папка |
|---|---|
| Каркас страницы и модальные окна | `index.html` |
| Общие темы и геометрия | `css/core.css` |
| Анимации | `css/animations.css` |
| Стили отдельных функций | `css/features/` |
| Только телефонная раскладка | `css/responsive/mobile.css` |
| Основное состояние и облако | `js/app.js` |
| Разрешение конфликтов ПК/телефон | `js/core/sync-merge.js` |
| Только мобильное поведение | `js/features/mobile-navigation.js` |
| Информация Academy/USAF и тесты | `data/academy/`, `data/usaf/` |
| Ступени и прогресс | `data/levels.js`, `data/progress/` |
| Изображения | `assets/images/` |

## Главное правило мобильной версии

Отдельный мобильный `index.html` не создаётся. Текст, тесты, ранги, прогресс и логика остаются общими. Телефон получает только `mobile.css` и `mobile-navigation.js`, поэтому новую информацию достаточно добавить один раз в соответствующий файл `data/`.

Новые правила только для телефона добавлять в `css/responsive/mobile.css`. Общие правила, которые должны работать и на ПК, и на телефоне, добавлять в обычные файлы `css/`.

## Как теперь работает синхронизация

Профиль разделён на независимые группы:

- ник;
- тема;
- выбранные проект, организация, отдел и ступень;
- задания, сохранённый прогресс и выбранные ступени;
- закреплённые материалы;
- данные аккаунта.

При конфликте сравнивается время изменения каждой группы. Поэтому изменение прогресса на телефоне больше не должно возвращать старый ник на ПК. После первого сохранения v68 старые профили автоматически получают новые служебные отметки времени; ключи локального хранилища при этом не менялись.

## Запуск

Папку можно открыть как статическую страницу, но для разработки и точной проверки подключений рекомендуется локальный HTTP-сервер. Для публикации на GitHub Pages загружается всё содержимое папки v68.
