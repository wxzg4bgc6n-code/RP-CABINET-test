# RP CABINET — TEST v112

## Что изменилось в v112

- Academy показывается в «Карьерном пути» только когда текущий отдел профиля — Academy.
- После перехода в USAF/MP/DF/SD/ED Academy скрывается даже если старый рендер попытался вернуть карточку.
- Добавлен независимый `career-path-guard.js`, который повторно проверяет карточку после каждого рендера и изменения отдела.
- Все подключения в `index.html` переведены на `?v=112`, чтобы браузер не использовал кэш v109/v111.
- Видимый бейдж версии: `TEST v112 · Career Academy hotfix`.

## Как загружать маленький пакет

Распакуй ZIP и загрузи **содержимое архива в корень репозитория** с заменой существующих файлов. В корне GitHub должен замениться именно `index.html`, а папки `js/` и `css/` должны слиться с существующими папками.

`js/config/public-config.js` в update-пакет не входит.
