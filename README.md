# RP CABINET — TEST v111

## Что изменилось в v111

- В «Карьерном пути» карточка Academy показывается только тогда, когда текущий отдел профиля — Academy.
- После перехода в USAF или другой отдел Academy исчезает из карьерного пути и больше не отображается как завершённая ступень.
- Текущий отдел продолжает отображаться и отслеживать выбранную ступень и процент повышения как раньше.
- Сетка карьерного пути теперь автоматически растягивает оставшиеся карточки по ширине, поэтому после скрытия Academy не остаётся пустого места.
- Все изменения v110 и v109 по материалам УАК/ПК сохранены.

## Постоянный публичный API key

`js/config/public-config.js` — локальная конфигурация развёртывания. При обычном обновлении этот файл **не заменять**.

Маленький update-пакет v111 его не содержит. В полном архиве вместо него лежит `js/config/public-config.example.js`, чтобы случайно не затереть уже настроенный ключ.

## Что загружать на GitHub

Для обычного обновления загружай содержимое маленького пакета поверх текущего репозитория, сохраняя структуру каталогов.

В корне проекта должны оставаться `index.html`, `report.html`, `favicon.ico`, `site.webmanifest`, `assets/`, `css/`, `data/`, `js/`, `documentation/`, `_tools/`, `README.md`, `build-summary.json`.

Не загружать `node_modules/`, `.env`, OAuth client secret, refresh token и старый `proof-service/`.

## История версий

### v111 — Career Academy visibility
Academy видна в карьерном пути только пока это текущий отдел; после перехода в USAF/другой отдел остаётся только текущий отдел.

### v110 — USAF law layout fix
Удалены служебные плашки USAF/Общее, блок «Какие темы УАК учить для армии», исправлены отступы карточек; «Улика» и «Ордер» приведены к общему виду.

### v109 — USAF law cleanup
Памятка УАК/ПК очищена от лишних служебных пояснений, обновлены алгоритм, вопросы и карточки требований к уликам.
