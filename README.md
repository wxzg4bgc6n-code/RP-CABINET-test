# RP CABINET — TEST v107

## Что изменилось в v107

- Полностью переделан первый экран создания профиля.
- Добавлено плавное приветствие «Добро пожаловать в RP CABINET».
- После приветствия показывается короткое объяснение возможностей панели.
- Создание профиля разделено на последовательные этапы: ник → проект и направление → организация.
- Между этапами используются мягкие переходы без резких скачков интерфейса.
- После выбора организации стартовый экран растворяется и открывает вкладку «Прогресс».
- Выбранная организация сразу переносится в профиль; раздел и ступень выбираются уже внутри панели.
- Добавлена адаптация анимаций и форм для телефона.
- Для систем с отключёнными анимациями вступление сразу переходит к вводу ника.

## Сохранено из v106

- У пользователей нет окна ручного ввода API-ключа.
- Публичный Google Drive API key хранится только в `js/config/public-config.js`.
- Новые ссылки отчётов не содержат параметр `pk`.
- Загрузка скриншотов не зависит от ключа публичных отчётов.

## Сохранено из v105

- Скриншоты после загрузки сразу добавляются в панель и сохраняются в Firebase.
- Полноэкранный просмотр работает без скачивания файла.

## Что загружать на GitHub

Для обычного обновления используй **маленький пакет** и загрузи всё его содержимое поверх репозитория, сохраняя структуру.

В корне проекта должны оставаться:

- `index.html`
- `report.html`
- `favicon.ico`
- `site.webmanifest`
- `assets/`
- `css/`
- `data/`
- `js/`
- `documentation/`
- `_tools/`
- `README.md`
- `build-summary.json`

Постоянный файл `js/config/public-config.js` при обычном обновлении **не заменять**.

Не загружать:

- `node_modules/`;
- `.env` и `.env.local`;
- OAuth client secret и refresh token;
- `proof-service/`.
