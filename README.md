# RP Cabinet v69 — мобильный интерфейс и синхронизация без откатов

Версия создана копией v68. Папка v68 и контрольная основа не изменены.

## Что загружать на GitHub

Загружать нужно **всё содержимое папки v69** с сохранением подпапок. Главная страница — `index.html`. Нельзя загружать только HTML: без `css/`, `js/`, `data/` и `assets/` панель будет неполной.

## Где менять проект

| Изменение | Место |
|---|---|
| Каркас страницы | `index.html` |
| Общие стили и темы | `css/core.css`, `css/features/` |
| Только телефонные размеры и расположение | `css/responsive/mobile.css` |
| Состояние и Firebase | `js/app.js` |
| Слияние изменений ПК/телефона | `js/core/sync-merge.js` |
| Только мобильное поведение | `js/features/mobile-navigation.js` |
| Academy/USAF и тесты | `data/academy/`, `data/usaf/` |
| Ступени и задания | `data/levels.js`, `data/progress/` |

## Телефон

Отдельного мобильного `index.html` нет. Телефон использует те же данные, что и ПК. В v69 увеличены аватар, ник, основное содержимое, кнопки и подписи нижнего меню. Длинный ник переносится в своей колонке и не может залезать на аватар.

## Синхронизация v69

Синхронизация больше не решает конфликты по часам телефона и ПК. Каждый клиент сохраняет локальную очередь только из реально изменённых полей и отдельных заданий. При отправке выполняется облачная транзакция:

1. загружается последняя версия профиля;
2. к ней применяются только локальные изменения;
3. облачная ревизия увеличивается;
4. локальная очередь очищается только после успешной записи.

Поэтому изменение прогресса на телефоне не отправляет обратно старый ник, а изменение ника на ПК не стирает новый прогресс телефона. Явное снятие галочки тоже синхронизируется.

После публикации v69 старые вкладки v68 на всех устройствах нужно закрыть или полностью обновить, иначе открытая старая вкладка продолжит работать по прежней схеме.

Подробности: `documentation/ARCHITECTURE.md`.
