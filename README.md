## Постоянный публичный API key

`js/config/public-config.js` — локальная конфигурация развёртывания. При обычном обновлении этот файл **не заменять**.

Маленький update-пакет v109 его не содержит. В полном архиве вместо него лежит `js/config/public-config.example.js`, чтобы случайно не затереть уже настроенный ключ.

## Что загружать на GitHub

Для обычного обновления загружай содержимое маленького пакета поверх текущего репозитория, сохраняя структуру каталогов.

В корне проекта должны оставаться `index.html`, `report.html`, `favicon.ico`, `site.webmanifest`, `assets/`, `css/`, `data/`, `js/`, `documentation/`, `_tools/`, `README.md`, `build-summary.json`.

Не загружать `node_modules/`, `.env`, OAuth client secret, refresh token и старый `proof-service/`.
