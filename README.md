# RP CABINET — TEST v108

## Что изменилось в v108

- Обновлены правила ARMY/USAF по материалам от 02–03.08.2026, которые пользователь прислал из тем GTA5RP.
- В тесте USAF исправлен Ammunation: ARMY/USAF больше не участвует в отбитии; со стороны госструктур участвуют только FIB, LSPD и LSSD.
- В памятку УАК/ПК добавлены актуальные ограничения госфракций, требования к уликам и правила допросов.
- Удалено устаревшее правило про минимальные 45 секунд улики: теперь акцент на полной записи ситуации от начала до конца.
- Полностью обновлён прайс-лист премий: КПП, патруль, арест, спецоперации, обучение, мероприятия и спец. связь.
- Отчётная неделя автоматически считается с воскресенья по субботу.
- Для премии спецоперации подтверждаются через логи меню фракции; исключения — Отбитие ФЗ/ФТ и Рейд/Оцепление.
- Старые выбранные активности премии автоматически пересчитываются по новому прайс-листу.
- Удаление публичного отчёта теперь мгновенно очищает ссылку и скриншоты в панели/Firebase, а Google Drive удаляется в фоне с очередью повторной попытки.
- Добавлен tombstone удалённого отчёта, чтобы старая вкладка не могла вернуть удалённую публичную ссылку.

## Постоянный публичный API key

`js/config/public-config.js` — локальная конфигурация развёртывания. При обычном обновлении этот файл **не заменять**.

Маленький update-пакет v108 его не содержит. В полном архиве вместо него лежит `js/config/public-config.example.js`, чтобы случайно не затереть уже настроенный ключ.

## Что загружать на GitHub

Для обычного обновления загружай содержимое маленького пакета поверх текущего репозитория, сохраняя структуру каталогов.

В корне проекта должны оставаться `index.html`, `report.html`, `favicon.ico`, `site.webmanifest`, `assets/`, `css/`, `data/`, `js/`, `documentation/`, `_tools/`, `README.md`, `build-summary.json`.

Не загружать `node_modules/`, `.env`, OAuth client secret, refresh token и старый `proof-service/`.
