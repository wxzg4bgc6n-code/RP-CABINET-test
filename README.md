# RP Cabinet v67 — модульная основа

Эта папка создана из подтверждённой версии 66. Корневой `index.html` v66 не изменён и остаётся контрольной копией.

## Запуск

Открывать `index.html` можно как статическую страницу. Для разработки и точной проверки подключений лучше запускать папку через локальный HTTP-сервер.

## Куда вносить изменения

| Что меняется | Файл или папка |
|---|---|
| Каркас главного меню и модальные окна | `index.html` |
| Порядок подключения стилей | `css/main.css` |
| Общая геометрия и темы | `css/core.css` |
| Анимации | `css/animations.css` |
| Тесты, поверхности, закрепления, промо | `css/features/` |
| Список организаций и отделов | `data/sections.js` |
| Ступени отделов | `data/levels.js` |
| Задания повышения | `data/progress/` |
| Тексты Academy | `data/academy/content.js` |
| Тесты Academy | `data/academy/tests.js` |
| Тексты USAF | `data/usaf/content.js` |
| Тесты USAF | `data/usaf/tests.js` |
| Состояние, прогресс и основной рендер | `js/app.js` |
| Независимые функции интерфейса | `js/features/` |
| Постоянные ключи профиля | `js/core/storage-config.js` |
| Номер тестовой версии | `js/core/version.js` |
| Изображения | `assets/images/` |

## Важные правила

- Данные подключаются до `js/app.js`; функции интерфейса — после него.
- Большие тексты, тесты, CSS и raster base64 не возвращаются в `index.html`.
- Закреплённая копия использует тот же шаблон, что основная вкладка.
- `KEY` и `VERSION_KEY` не меняются из-за номера интерфейса.
- Новая крупная версия создаётся копией последней подтверждённой модульной папки.
- Новый отдел получает собственные `data/<отдел>/`, `data/progress/<отдел>.js` и при необходимости `css/features/<отдел>.css`.

Подробный порядок расширения: [documentation/ARCHITECTURE.md](documentation/ARCHITECTURE.md).
