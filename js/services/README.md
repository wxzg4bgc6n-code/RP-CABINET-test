# Сервисы

- `google-drive-storage.js` — OAuth access token текущего пользователя, ограниченный по времени локальный кэш с UID-проверкой, папки, загрузка, публичное чтение и очистка файлов Google Drive.
- Совместимая логика Firebase остаётся в `../app.js`.

В клиентских файлах допускается ограниченный браузерный API key. OAuth client secret, refresh token и другие секреты сюда помещать нельзя.
